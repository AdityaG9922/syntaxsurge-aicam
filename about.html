Project

Built for curiosity

Syntax Surge is a personal AI experimentation platform — a collection of browser-based vision tools built from scratch to explore what's possible with modern web APIs and open-source AI libraries.

The Idea

I wanted to build something that felt like a real tool — not a demo, not a tutorial project. Something that's actually useful when you're standing in front of a plant you don't recognise, or trying to digitise a handwritten receipt, or just curious what an AI "sees" when it looks at your photo.

Every module runs entirely in the browser. Nothing is sent to a server. Your images never leave your device.

How It Works

Syntax Surge is built with plain HTML, CSS, and JavaScript — no frameworks, no build tools. Each AI capability is powered by an open-source library loaded on demand so the initial page loads fast.

The visual design was handcrafted from scratch. Every animation, cursor effect, and layout decision was written by hand.

Tech Stack

The tools and libraries powering each module:

Tesseract.js — OCR jsPDF — PDF export Canvas API — Drawing MediaDevices API — Camera GSAP-ready — Animation Vanilla JS — Core CSS Custom Properties IntersectionObserver

Creator

Built entirely by Aditya — a developer who believes good tools don't need to be complicated, just focused.

Syntax Surge is an ongoing experiment. New modules get added when something interesting becomes possible in the browser.
